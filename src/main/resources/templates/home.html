Spring Web Flow Demo

Spring Web Flow là framework giúp quản lý các màn hình nhiều bước theo dạng state và transition. Nó phù hợp khi bạn có quy trình cần giữ trạng thái giữa nhiều request như đăng nhập nhiều bước, wizard đăng ký, checkout, quên mật khẩu hoặc xác nhận OTP.

Login Flow trong demo

[loginForm] --submit--> [validateInput] --valid--> [authenticateUser] --success--> [loginSuccess] --finish--> [flowEnd] ^ | | | | invalid | failure | v v +------------------ [validationError] <---- [loginFailed]

Khi nào nên dùng?

  • Khi quy trình có nhiều bước và mỗi bước phụ thuộc trạng thái của bước trước.
  • Khi bạn muốn tách rõ phần điều hướng luồng ra khỏi controller Java.
  • Khi cần resume flow execution qua nhiều request nhưng vẫn giữ dữ liệu trung gian.
